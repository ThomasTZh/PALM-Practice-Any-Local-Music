# M3.12 plan — Musical snapping

Spec: `projectPlans/milestone3.md` §14 (M3.12). Adds edit-time snapshot
resolution in source frames with visual-radius semantics and a validated
API, plus the TypeScript geometry for responder-side previews.

## Scope

In:
- Snap modes off/beat/half-beat/quarter-beat/bar/event.
- 8 CSS-pixel radius converted by viewport scale; nearest eligible
  target only; otherwise preserve position.
- Primary grouping, exact musical subdivisions through the tempo map,
  bar boundaries, event boundaries.
- Modifier inversion and server validation endpoint.
- Python and TypeScript tests.

Out:
- Drag-handler integration and the final platform modifier binding (editor
  interaction layer).
- Retroactive quantization, which is prohibited by design.
