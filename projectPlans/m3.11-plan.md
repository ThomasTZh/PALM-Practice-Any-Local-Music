Spec: `projectPlans/milestone3.md` §13 (M3.11). Adds the musical ruler,
tempo/meter/beat lanes, inspector, hit testing, and performance isolation
above the existing waveform viewport.

- Pure TypeScript ruler geometry (`frontend/src/music/ruler.ts`):
  zoom-dependent detail, binary-search viewport culling, label overlap
  suppression, priority hit testing with minimum handle width.
- Five Vitest cases covering the geometry.

- Layered rendering (bars, primary beats, subdivisions, meter labels,

  hover.
- Tempo/meter/beat lane visuals, lock/uncertainty/manual indicators.
- Inspector fields and keyboard alternatives.
- Selection/drag integration with M3.10 commands.
- Performance budget and visual alignment acceptance at all zooms.
- Data wiring through rhythm APIs (M3.17).
