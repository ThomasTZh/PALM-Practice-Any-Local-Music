# M1.16 plan — Test corpus and automated verification

Spec: `projectPlans/milestone1.md` §18. This is the final Milestone 1
work package.

Goal: complete the automated test corpus against the §18.1–§18.7
checklists. Consolidate the scattered local fixture helpers
(`_make_wav` in `test_media_worker.py`, `_write_wav`/`_sine`/`_encode`
in `test_decode.py`) into one shared synthetic fixture module; add
ffmpeg-based format fixtures; fill the identified test gaps. Where a
new test exposes a genuine product bug, fix the product code in this
work package (no behavior changes that are not bug fixes).

Out of scope: §19 browser/performance/listening acceptance (manual
platform gate, not automatable here); looping (post-Milestone 1).

## 3. Fixture module design (`tests/synth.py`)

Signal generators — all return `numpy` `<f4` arrays (mono `(N,)`,
multi `(N, C)`):

- `sine(seconds, rate, freq=440, amp=0.5, channels=1)`
- `stereo_tones(seconds, rate, freq_l, freq_r)` — distinct L/R
  frequencies (channel-order oracle).
- `impulses(total_frames, rate, at: int | list[int], channels=1, value=1.0)`
  — sample-exact impulses at known frames.
- `silence(frames, rate, channels=1)`
- `dc_offset(frames, rate, offset=0.25)`
- `full_scale(frames, rate)` — alternating ±1.0.
- `above_full_scale(frames, rate, peak=2.0)` — finite values > 1.
- `short_in_bucket(frames, rate, channels=1)` — length deliberately
  not a multiple of the 64-frame peak bucket (final partial bucket).
- `block_edge_impulses(total_frames, rate, channels=1)` — impulses
  placed one frame before/after 64-frame bucket edges and tile
  boundaries (processing-block crossings).
- `channel_impulses(frames, rate, channels)` — one impulse per
  channel at a distinct frame (5.1 = 6, 7.1 = 8).
- `long_recording(seconds, rate, channels=1)` — the 60-minute
  fixture, generated on demand (never committed).

Writers:

- `write_wav_s16(path, samples, rate)` — 16-bit PCM (existing
  pattern, generalized).
- `write_wav_f32(path, samples, rate)` — IEEE float WAV (format tag
  3); required for above-full-scale content (s16 clips).
- `encode_with_ffmpeg(input, output, *extra)` — the shared
  subprocess helper (moved from `test_decode.py`).

Timestamp gap/overlap (§18.1.13/14): file-level fixtures are not
constructible with this toolset (container muxers normalize audio
timestamps) — the `aresample=async=1` policy is exercised at the
filter level (existing `TestResamplerPolicy`), documented in the
module docstring.

## 4. Format fixture matrix (§18.2)

Generated with the installed ffmpeg 8.1.2 (verified encoders:
`pcm_s16le`, `pcm_f32le`, `flac`, `libmp3lame`, `aac`, `libvorbis`,
`libopus`):

| Fixture | Command shape |
| --- | --- |
| PCM WAV / float WAV | `write_wav_s16` / `write_wav_f32` |
| FLAC | `-c:a flac` |
| MP3 CBR | `-c:a libmp3lame -b:a 192k` |
| MP3 VBR | `-c:a libmp3lame -q:a 4` |
| AAC/M4A | `-c:a aac -f m4a` |
| Ogg Vorbis | `-c:a libvorbis -f ogg` |
| Opus | `-c:a libopus -f ogg` |
| AIFF | `-c:a pcm_s16le -f aiff` |
| Video, one audio stream | lavfi `testsrc` + `sine` → `.mp4` |
| Video, two labeled audio streams | two `sine` inputs, distinct `metadata=title=` per stream → `.mp4` |
| Video without audio | lavfi `testsrc` only → `.mp4` |
| Audio with cover art | sine audio + generated `mjpeg` art stream, `-disposition:v:0 attached_pic` → `.mp4` |

`tests/integration/test_formats.py` round-trips each: encode →
`decode_canonical` → assert sample rate, channel count, frame count
within codec-delay tolerance (lossy) or exact (lossless), finite
samples, nonzero energy. The capability probe records which
combinations the installed build supports; unsupported →
`pytest.skip(reason)`. Results recorded in
`docs/evidence/m1.16-format-capabilities.md`.

## 7. Risks / notes

- The 60-minute fixture is ~320 MB (mono 44.1 kHz s16) in tmp;
  generate once per test session where used, keep the consuming test
  bounded (multi-tile pyramid shape + determinism, not full
  re-verification).
- Lossy frame counts carry codec delay/priming; keep the existing
  ±30 % tolerance and the byte-identical-re-decode determinism check.
- mp4/video fixtures need the `libx264`/`mpeg4` video encoders — the
  capability probe decides; if video encoding is unavailable, the
  video fixtures skip with a recorded reason (audio-stream selection
  is already covered by the multi-stream import tests).
- `tests/synth.py` is imported by tests only (no `src/` changes), so
  ruff/mypy scope is unchanged.
