# M1.5 — Decode canonical audio: implementation plan

Scope per `projectPlans/milestone1.md` §7. This makes `canonical_decode` a
fully-executable job type: the worker decodes the selected audio stream to
interleaved float32le raw PCM in staging, validates it, and the backend
publishes the asset + canonical representation and transactionally attaches
both to the project.

**Acceptance property:** canonical audio has a reproducible sample count,
preserved channel structure, and a defined time origin.

**Verified FFmpeg behavior (ffmpeg 8.1.2, experiments in /tmp/opencode/gaptest):**
- Decode command `ffmpeg -hide_banner -nostdin -v warning -threads N -i src
  -map 0:<global_index> -af aresample=async=1 -c:a pcm_f32le -f f32le
  -progress pipe:2 out.pcm` works; the explicit global-index map selects the
  probe-verified stream and excludes video/subtitle/data.
- `aresample=async=1` (single option; default `min_hard_comp=0.1` s) =
  "filling and trimming": a +1 s forward gap yields exactly +48000 padded
  samples @48 kHz (silence), a −0.5 s overlap yields exactly −24000 trimmed
  samples. No gradual speed correction. On a clean stream it is a no-op
  (frame count identical with/without the filter).
- Progress arrives on stderr as `key=value` blocks ending in
  `progress=continue|end`; `out_time_us` is the decoded-time marker.
- Codec delay/priming for a 1 s @44100 mono file: mp3 → 44100 frames,
  aac/m4a → 45056, opus/ogg → 48000. Deterministic across runs (identical
  SHA-256). We keep decoder-primed samples (no double trim) — the decoded
  count is the authoritative sample count.
- Zero-sample input → ffmpeg exit 0 with a 0-byte output file (worker must
  map this to `EMPTY_AUDIO`).
- Truncated media can exit 0 with decoder warnings on stderr (e.g. mp3
  `invalid new backstep -1`) → recorded in the result, never a silent clean
  import.
- File-level gap/overlap fixtures are not constructible with this toolset
  (MP3/M4A/MKV/TS muxers normalize audio timestamps; the concat demuxer
  ignores `#outputts_offset` in this build; the HLS demuxer hangs). The
  discontinuity policy is therefore integration-tested at the resampler
  level with `asetpts`-shifted frames — the exact component the production
  filter configures.

## 1. Shared subprocess helpers — new `src/basseparate/media/_process.py`

Move out of `probe.py` (which re-imports them):
- `_terminate_graceally(proc)` — `terminate()` → wait ≤5 s → `kill()`.
- `_wait_for_cancel(cancel_event, proc, poll=0.1)` — returns True when the
  event is set; the caller terminates.
- `read_stderr_bounded(proc, max_bytes)` — incremental bounded stderr reader
  (asyncio), keeping the last N lines + total byte count.

`probe.py` keeps its public API unchanged.

## 2. Decode engine — new `src/basseparate/media/decode.py`

`decode_canonical(*, source_path, output_path, stream_index, sample_rate,
channel_count, max_threads=4, channel_layout=None,
estimated_duration_seconds=None, start_timestamp_seconds=None,
cancel_event=None, on_progress=None, timeout_seconds=1800.0)
-> CanonicalDecodeResult`

Sequence (§7.2):
1. Source must exist, else `DecodeFailedError`.
2. Estimate output bytes = `estimated_duration × rate × channels × 4`
   (when known) × 1.25 headroom; check `shutil.disk_usage` free space →
   `InsufficientDiskSpaceError`.
3. Spawn ffmpeg (arg array, stdin=DEVNULL, stdout=DEVNULL, stderr=PIPE) with
   the verified command shape above. No `-ar`/`-ac` (rate + channels +
   layout preserved), no `-ss`/`-t` (no trim; decoder priming/padding is the
   time origin — §7.3).
4. Read stderr incrementally (bounded): parse progress blocks
   (`out_time_us`, `dup_frames`, `drop_frames`); throttle `on_progress` to
   ≥0.25 s spacing; collect warning lines (at `-v warning` level these are
   decoder warnings) capped at 20.
5. Cancel: `cancel_event` → graceful terminate → `DecodeCancelledError`
   (staged file removed by the worker).
6. Timeout (`asyncio.timeout`) → `DecodeTimeoutError`.
7. Exit code ≠ 0 → `DecodeFailedError` (stderr tail in the message).
8. File checks: missing/0-byte → `EmptyAudioError`;
   `size % (channels × 4) ≠ 0` → `DecodeFailedError` (frame alignment);
   `frame_count = size // (channels × 4)`.
9. Chunked validation pass (8 MiB chunks, one pass): SHA-256,
   `numpy.frombuffer(chunk, "<f4")` `isfinite` (→ `NonFiniteSamplesError`),
   max abs amplitude. Chunk size is a multiple of 4 so float boundaries are
   safe.
10. Duration bookkeeping: `decoded_duration = frame_count / rate`;
    `duration_discrepancy = decoded − estimated` (when estimated known);
    `timing_repair_warnings` when `|discrepancy| > 0.5 s` (well above codec
    delay; catches gap padding / overlap trim).
11. `decoder_warnings` from the stderr scan (truncated media is not a
    silent clean import).
12. Build `CanonicalDecodeResult` (model in `domain/representation.py`):
    `frame_count ≥ 1`, `sample_rate`, `channel_count`, `channel_layout?`,
    `content_hash`, `max_amplitude ≥ 0`, `pcm_byte_count`,
    `decoded_duration_seconds`, `estimated_duration_seconds?`,
    `duration_discrepancy_seconds?`, `source_start_timestamp_seconds?`,
    `decoder_warnings[]`, `timing_repair_warnings[]`, `ffmpeg_version`,
    `profile_version = 1`, `staging_pcm_path` (absolute; the publisher moves
    it).

Also in this module: `DecodeProgress` dataclass, `parse_progress_line`,
`compute_transform_key(source_sha256, stream_index, profile_version,
ffmpeg_version) -> Sha256Hash` (SHA-256 over canonical JSON:
`{v:1, source_sha256, stream_index, profile_version, ffmpeg_version,
sample_format:"f32le", channel_policy:"preserve",
timestamp_policy:"decoder-default", resample_policy:"async-fill-trim"}` —
M1.6 formalizes the full key content), `mime_type_for_format(format_name)`
(map wav/mpeg/aac/ogg/flac/mp4… with `audio/x-generic` fallback).

Error → code mapping (worker): `DECODE_FAILED`, `EMPTY_AUDIO`,
`NONFINITE_SAMPLES`, `INSUFFICIENT_DISK_SPACE`, `DECODE_TIMEOUT`,
`DECODE_PARAMETERS`.

Export from `media/__init__.py`.

## 3. Worker — `src/basseparate/worker/media_worker.py`

Replace the `CANONICAL_DECODE` `JOB_TYPE_NOT_IMPLEMENTED` stub:
- `_run_canonical_decode(payload, cancel_event)`:
  - `progress(decoding)` first.
  - Read `parameters` (required: `stream_index:int ≥ 0`,
    `sample_rate:int ≥ 1`, `channel_count:int 1..8`; optional:
    `channel_layout`, `estimated_duration_seconds`,
    `start_timestamp_seconds`). Malformed → `failed(DECODE_PARAMETERS)`.
  - `asyncio.run(decode_canonical(..., on_progress=throttled emit))` into
    `staging/canonical.pcm`.
  - Success → `completed(result=CanonicalDecodeResult.model_dump(mode="json"))`.
  - `DecodeCancelledError` → remove staged file → `cancelled(staging_removed)`.
  - `DecodeError` → `failed(mapped code, message)`.
- No protocol changes (v2 `run.parameters` already exists).

## 4. Job manager — `src/basseparate/jobs/manager.py`

- New injectable `parameters_for: Callable[[MediaJob], dict[str, Any]] |
  None`. In `_run_job`, for `canonical_decode` with `import_id`:
  `params = parameters_for(job)`; empty → `fail_job(NO_STREAM_SELECTION)`
  before the worker is involved. Pass `params` to `make_run(...)`.
- `_publish` re-ordering (required for safe publish, §8.3.8: "mark the job
  complete only after the references are committed"):
  1. verify the result against the per-type model (`PROBE` → `ProbeResult`,
     `CANONICAL_DECODE` → `CanonicalDecodeResult`) → failure:
     `fail_job(RESULT_VERIFICATION)`;
  2. run the publisher while the job is still `running` → exception:
     `fail_job(PUBLISH_FAILED)`;
  3. `complete_job(job_id, result)`.
- Publisher signature becomes `Callable[[MediaJob, dict[str, Any]], None]`
  (job + verified result dict); update `build_import_publisher` to match
  (probe behavior unchanged).

## 5. Publisher — new `src/basseparate/jobs/publisher.py`

`build_publishers(import_repo, project_repo, representation_repo,
storage_root) -> Callable[[MediaJob, dict], None]` dispatching by job type.

`_publish_decode(job, result)`:
1. `import_record` by `job.import_id`: must exist, be `COMPLETE`, have a
   `probe_result` and `selected_stream_index`; the selected stream must
   match the result's `sample_rate`/`channel_count` (backend re-verification
   of §7.2.1).
2. Canonical PCM: destination `storage_root/data/assets/<content_hash>.pcm`
   (content-addressed from the start — M1.6 keeps this layout). Dedup:
   `get_asset_by_hash(content_hash)` → reuse the asset ID; if the file
   exists, skip the move and remove staging; else `shutil.move` (same
   filesystem → atomic rename).
3. Original-file asset: `get_asset_by_hash(import.source_sha256)` → reuse,
   else new `AssetRecord(role=SOURCE_ORIGINAL, relative_path=
   "runtime/uploads/<import_id>.part", media_type=mime_type_for_format(...),
   byte_count=received_byte_count)`.
4. `AudioRepresentation(asset_id=pcm, parent_asset_id=original,
   role=CANONICAL, sample_rate, channel_count, channel_layout, frame_count,
   content_hash, transform_key=compute_transform_key(...),
   time_mapping=TimeMapping(rate, rate) (identity),
   provenance=(ffmpeg, result.ffmpeg_version, 1, now))`.
5. `ProjectRepository.publish_source(project_id, original_asset, pcm_asset,
   representation, source_fields)` — one transaction (below).
   `source_fields`: `source_asset_id`, `canonical_asset_id`,
   `source_stream_index`, `sample_rate`, `duration_frames=frame_count`,
   `source_channel_count`, `source_channel_layout`,
   `decode_profile_version=1`, `source_metadata` = JSON
   `{decoder_warnings, timing_repair_warnings, max_amplitude,
   duration_discrepancy_seconds, source_start_timestamp_seconds}`,
   `status="ready"`.
6. Idempotent: re-decoding the same import reuses both assets,
   `INSERT OR IGNORE` on `project_assets`/`representations`, and re-sets the
   same project fields.

## 6. Storage — `src/basseparate/storage/repository.py`

- `ProjectRepository.get_asset_by_hash(content_hash) -> AssetRecord | None`.
- `ProjectRepository.publish_source(...)` — single
  `BEGIN IMMEDIATE … COMMIT`:
  - insert `assets` rows only for hashes not present (publisher dedups);
  - `INSERT OR IGNORE` `project_assets` (original as `source_original`, PCM
    as `source_pcm`);
  - `INSERT OR IGNORE` `representations` (PK `asset_id`);
  - `UPDATE projects` setting **all eight** source-readiness fields together
    (+ `source_metadata`, `status='ready'`, `updated_at`) — the
    co-presence invariant in `ProjectRecord` holds by construction.
  - return the refreshed `ProjectRecord`.
- No new migration (schema v3 is sufficient).
- Exports in `storage/__init__.py` where applicable.

## Confirmed design points

1. Raw PCM file (no WAV header): `f32le` interleaved, rate/channels/order
   preserved from the probe-verified selected stream.
2. Time origin = decoded stream start after decoder priming/padding;
   container start time recorded in the result; no silence prepending, no
   double trim.
3. Discontinuities: `aresample=async=1` (gaps → silence, overlaps → trim,
   no speed correction); repair recorded via the decoded-vs-estimated
   duration discrepancy (>0.5 s warns).
4. Out-of-range sample values (|x| > 1) are kept verbatim; `max_amplitude`
   recorded.
5. Publish ordering: verify → publisher (assets + transactional attach) →
   `complete_job`. A failed publish fails the job; a completed job always
   has its references committed.
6. Content-addressed `data/assets/<sha256>.pcm` with hash-based dedup from
   day one (M1.6 keeps the layout and adds budgeting).
7. Single M1.5 commit at the end.
