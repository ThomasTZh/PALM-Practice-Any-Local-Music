# M3.7 plan — Build the tempo map

Spec: `projectPlans/milestone3.md` §9 (M3.7). Seventh Milestone 3 work
package. Turns accepted decoded pulses and explicit anchors into a
strictly monotonic source↔musical map with versioned pulse-unit
hypotheses. Meter/bars and command/UI integration remain later.

**Acceptance (§9):** the tempo map preserves timing variation, supports
half/double interpretation and manual anchors, and maps source↔musical
positions reversibly within documented rounding tolerance.

## Scope in / out

In:
- `domain/tempo.py`: `PulseUnit`, `PulseUnitHypothesis`, standard,
  denominator, and grouping hypotheses; `TempoMapAnchor`,
  `TempoMapSegment`, `TempoMap` with exact interpolation/inversion,
  local BPM, summary BPM, range errors, monotonic validation.
- `rhythm/tempo.py`: automatic map construction from accepted pulses
  (one anchor per pulse), sparse/manual map construction, half/double
  region reinterpretation with locked-anchor conflicts, display-unit BPM
  conversion, round-trip diagnostic.
- Tests and real-model evidence.

Out:
- Meter inference/regions (M3.8), bars/beats/pickups (M3.9).
- Persisting maps into branches/automatic-result stages (M3.9) and
  revisioned edit/undo commands (M3.10).
- Frontend musical-map service and Python/TS golden fixture agreement
  (Gate C; service M3.17, fixtures with M3.9).
- Metronome scheduling (M3.14).

## Decisions

1. **Exact rational math.** Mapping uses `Fraction`; rounding half-up
   once. Round-trip tolerance is one frame; evidence measured zero.
2. **One anchor per accepted pulse.** Musical positions accumulate by
   the selected pulse-unit distance. No global-BPM fit; natural variation
   stays in the anchors/segments.
3. **BPM is derived.** Segment BPM and a median summary BPM are stored as
   display/search metadata, never as the authoritative map. Summary unit
   is explicit quarter-note BPM.
4. **No silent extrapolation.** Outside the first/last anchor is an
   error; the model carries a zero edge-extension budget for future
   explicit pickup/count-in needs.
5. **Reinterpretation rescales musical distance only.** Source frames
   stay fixed. Half-time doubles distances, double-time halves them. The
   start anchor is fixed; locked anchors raise conflicts instead of
   moving; crossed neighbors are rejected.
6. **Manual/sparse maps are first-class.** Two explicit anchors are
   enough for quarter positions and a neutral click; bar features remain
   gated on meter.
7. **Hypotheses are versioned data.** Selected unit, distances, labels,
   alternatives, and meter requirement travel with the map for audit and
   later decoder/tempo comparison.
