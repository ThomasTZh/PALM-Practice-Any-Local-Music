# M3.8 plan — Infer and edit meter regions

Spec: `projectPlans/milestone3.md` §10 (M3.8). Eighth Milestone 3 work
package. Adds feature evidence, candidate scoring, ambiguity/unmetered
results, and validated manual meter regions. Automatic multi-region
sequence decoding is deferred; manual regions already support changes.

**Acceptance (§10):** meter inference remains separate from beat
detection, supports simple/compound/irregular candidates, exposes
ambiguity, and permits arbitrary manual correction at bar boundaries.

## Scope in / out

In:
- `domain/meter.py`: versioned feature profile/artifact, candidate set
  with groupings and display units, scoring profile and components,
  alternatives/uncertainty/unmetered selection, automatic result,
  validated multi-region `MeterMap`, arbitrary manual meter entry.
- `rhythm/meter.py`: bounded-memory accent/onset extraction and managed
  feature store; candidate/phase scoring; single-region automatic
  inference with runner-ups, margin, uncertain/unmetered states.
- Tests with synthetic features and a real-model extraction/inference.

Out:
- Automatic multi-region meter changes and full Viterbi transition
  decoding (deferred to M3.10 editing/sequence work; manual regions
  support changes now).
- Persisting meter into branches/results (M3.9).
- Meter UI, hatching, alternative selection (M3.17).
- Calibrated probabilities.

## Decisions

1. **Features are versioned, compact, separate evidence.** Accent and
   onset arrays live in their own managed store; they never replace or
   masquerade as Beat This! activations.
2. **Bounded memory extraction.** PCM is memory-mapped and processed in
   chunks; only arrays plus FFT windows are live.
3. **Explicit candidates and groupings.** 5/4 and 7/8 keep multiple
   plausible groupings; grouping sums are validated.
4. **Ambiguity is a first-class outcome.** The margin against the
   runner-up marks a region uncertain; alternatives are retained.
   Insufficient evidence yields `unmetered` with no bars.
5. **Scores are uncalibrated.** Components and weights are recorded;
   confidence is heuristic/calibrated=false.
6. **Manual meter is less restricted than automatic candidates.**
   Arbitrary positive numerators/denominators and groupings are allowed;
   only whole-bar ordering is enforced.
7. **One automatic region now.** The real fixture demonstrates the
   ambiguity path; multi-region automatic changes wait for the editing
   command layer, while `MeterMap` already validates manual changes.
