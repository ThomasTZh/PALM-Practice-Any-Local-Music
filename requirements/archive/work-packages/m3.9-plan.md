## Scope in / out

Out:

## Decisions

1. **Derive, do not persist grid lines.** Only events for the requested
   range/detail are generated; a hard event bound rejects unbounded
   requests.
2. **Exact fractions until the final hop.** Events carry the exact source
   fraction and one half-up rounded frame; backend and TS use the same
   rule.
3. **One numbering timeline.** Bars before the first numbered bar are
   pickup; numbering continues through meter changes; a new meter region
   starts at beat 1 of a new bar.
4. **No grid in unmapped gaps.** Explicit gaps suppress events/snaps and
   are reported to the caller.
5. **Branch carries grid data.** Tempo anchors/meter regions become
   branch records; automatic uncertainty stays visible as `uncertain`
   validity rather than being coerced to valid.
6. **Shared fixture is the contract.** Both implementations consume one
   JSON file; neither duplicates hand-maintained expectations.
