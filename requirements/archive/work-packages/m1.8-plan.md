## 2. Cache layout

```
cache/waveforms/<source_hash>/
  manifest.json              # atomic rewrites (tmp + fsync + rename)
  level_0/tile_000000.bin    # 4096 buckets each, except a level's last tile
  level_0/tile_000001.bin
  level_1/...
```

- `source_hash` = SHA-256 of the canonical PCM (asset `content_hash`).
- One bucket = signed min + max per channel, f32le.
  Tile bytes (full) = `4096 · channel_count · 8`; a level's last tile is
  `final_tile_buckets · channel_count · 8`.
- Geometry: level L bucket = `64 · 4^L` frames; level L bucket count =
  `ceil(frame_count / (64·4^L))`. Coarsest level = smallest L with
  bucket count ≤ 4096 (fits one tile).

### Manifest (JSON)

```json
{
  "cache_version": 1,
  "source_hash": "<sha256>",
  "sample_rate": 44100,
  "frame_count": 2646000,
  "channel_count": 2,
  "base_bucket_frames": 64,
  "aggregation": 4,
  "levels": [
    {"bucket_frame_count": 64, "bucket_count": 41344,
     "tile_count": 11, "final_tile_buckets": 2048},
    {"bucket_frame_count": 256, "bucket_count": 10336,
     "tile_count": 3, "final_tile_buckets": 2144},
    {"bucket_frame_count": 1024, "bucket_count": 2584,
     "tile_count": 1, "final_tile_buckets": 2584}
  ],
  "available_tiles": {"0": [[0, 9]], "1": [[0, 2]], "2": [[0, 0]]},
  "final": false
}
```

`available_tiles` maps level index → list of inclusive `[first, last]`
completed-tile ranges (progressive publication, §10.3). The on-disk manifest
is the source of truth for availability; the DB row only pins the final cache
to the asset. The worker never touches the DB (M1.4 boundary) — it writes
tiles + manifest files only.

## 3. Domain — `src/basseparate/domain/waveform.py` (new)

```python
WAVEFORM_CACHE_VERSION = 1
BASE_BUCKET_FRAMES = 64
AGGREGATION = 4
TILE_BUCKETS = 4096

class WaveformLevelSummary(BaseModel):
    bucket_frame_count: int
    bucket_count: int
    tile_count: int
    final_tile_buckets: int

class WaveformResult(BaseModel):          # worker → publisher
    cache_version: int
    source_hash: str
    sample_rate: int
    frame_count: int
    channel_count: int
    final_bucket_frames: int              # true frames in level-0 last bucket
    levels: list[WaveformLevelSummary]
    manifest_path: str                    # absolute path of final manifest

class WaveformManifest(BaseModel):        # on-disk manifest, parseable
    cache_version: int
    source_hash: str
    sample_rate: int
    frame_count: int
    channel_count: int
    base_bucket_frames: int = 64
    aggregation: int = 4
    levels: list[WaveformLevelSummary]
    available_tiles: dict[str, list[list[int]]]
    final: bool
```

Helpers:
- `expected_levels(frame_count, channel_count) -> list[WaveformLevelSummary]`
  (pure geometry, used by worker param validation and tests).
- `tile_byte_count(buckets, channel_count) -> int`.
- `validate_manifest(m: WaveformManifest, *, source_hash: str) -> None`
  (cache version, hash, geometry consistency, `min ≤ max` not applicable —
  that is per-tile).
- `validate_tile_bytes(data: bytes, expected_len: int) -> None`
  (length, finiteness, `minimum ≤ maximum` — §10.4; numpy view).

Export from `basseparate.domain`.

## 4. Engine — `src/basseparate/media/waveform.py` (new)

```python
def build_waveform_cache(
    source_path: Path,
    cache_dir: Path,
    *,
    sample_rate: int,
    frame_count: int,
    channel_count: int,
    block_bytes: int = 4 * 1024 * 1024,
    cancel_event: threading.Event | None = None,
    on_progress: Callable[[float], None] | None = None,
) -> WaveformManifest
```

Streaming algorithm (§10.2), bounded memory:

1. Precompute level geometry from `frame_count` (all levels known up front).
2. Read the PCM in `block_bytes` chunks (rounded down to a multiple of
   `channel_count · 4`); carry the tail samples that do not fill a base
   bucket between blocks.
3. Per level, keep a bounded partial-bucket buffer (≤ 4096 + 3 buckets).
   Drain loop after every block:
   - 4 complete buckets at level L → 1 bucket at level L+1 (numpy min/max of
     the 4 buckets' extrema);
   - 4096 complete buckets at level L → write that level's next tile.
4. Tile write is atomic: `tile_XXXXXX.tmp` → fsync → `rename`; then rewrite
   the manifest atomically with the tile's inclusive range added to
   `available_tiles` (progressive publication — completed regions are
   visible while later tiles are pending).
5. EOF: flush the partial last tile at every level (it is immutable once the
   stream ends — all its buckets are known), record
   `final_bucket_frames` (true frames of the level-0 last bucket, §10.2.9),
   write the final manifest (`final: true`).
6. Never pad incomplete buckets with zeros (§10.2) — partial buckets keep
   their true sample count; extrema are computed over the real samples only.
7. Cancellation: `cancel_event` is checked between blocks; on cancel (or any
   failure) delete the whole `cache_dir` and re-raise — a failed run leaves
   no partial cache behind (rebuilds are cheap; the source is untouched).
8. `on_progress(fraction)` after each block (frames processed / total).

Memory: one 4 MiB block + level buffers (≤ 4099 buckets · ch · 8 B ≈
260 KiB at 8 ch) + numpy temporaries → well under the 256 MiB bound
(§10.5). No whole-file load.

## 8. Publisher — `src/basseparate/jobs/publisher.py`

- `build_publishers(..., job_repository)` (new last parameter).
- `_publish_waveform(job, result, project_repository, cache_repository,
  paths)`:
  1. Load the manifest file from `result.manifest_path`; require
     `final: true` and `source_hash` match.
  2. `validate_manifest(...)`; spot-check the last tile of level 0
     (`validate_tile_bytes`) before registering.
  3. `cache_repository.register(canonical_asset_id, result)`.
  4. Idempotent: existing row → no-op.
- **Auto-queue (§10.3.1):** at the end of `_publish_decode` (canonical
  committed), create a `WAVEFORM` job for the project unless a WAVEFORM job
  already exists for it (re-decode safe). This is the only place a waveform
  job is created automatically; manual re-runs use the normal job route.

## 11. Tests (backend)

- `tests/unit/test_waveform.py` (new, engine — no worker subprocess):
  - Exact level-0 extrema vs direct numpy computation (sine, noise).
  - All-positive and all-negative signals (no zero padding may skew extrema).
  - Block-boundary invariance: tiny blocks (e.g. 3 buckets worth) vs one
    pass → byte-identical tiles and manifest.
  - Channel boundaries: 1, 2, 3, 8 channels (odd channel counts are not a
    multiple of any power of two).
  - Partial final bucket: frame count not a multiple of 64 →
    `final_bucket_frames` exact; geometry (level/tile counts) matches
    `expected_levels`.
  - Long file: ≥ 1 M frames, multi-tile at several levels; availability
    ranges monotonic; `final: true` only at the end.
  - Determinism (two runs byte-identical).
  - Cancellation mid-build → `cache_dir` removed, no partial files.
  - Validation: `validate_tile_bytes` rejects wrong length, non-finite,
    `min > max`; `validate_manifest` rejects hash/version/geometry mismatch.
- `tests/integration/test_media_worker.py`: WAVEFORM run end-to-end (real
  worker subprocess, real file); parameter validation failures;
  `JOB_TYPE_NOT_IMPLEMENTED` tests switch fixture away from `WAVEFORM`.
- `tests/integration/test_publisher.py`: `_publish_waveform` (register,
  idempotent re-publish, rejects non-final manifest, rejects hash mismatch);
  auto-queue after `_publish_decode`.
- `tests/integration/test_job_manager.py`: WAVEFORM parameter resolution
  (valid params incl. `cache_dir`; `NO_CANONICAL`).
- `tests/unit/test_storage_db.py`: schema v5 migration + table shape.
- All `build_publishers` call sites gain the `jobs` argument (app + 4 tests).
